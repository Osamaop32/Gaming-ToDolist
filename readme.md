
# 🎮 Gaming ToDo List

A modern and stylish Gaming ToDo List built with HTML, CSS, Tailwind CSS, and JavaScript.

## 🚀 Features

- ➕ Add new tasks
- ✏️ Edit existing tasks
- ❌ Delete tasks
- 🔍 Search tasks
- ✅ Mark tasks as completed
- 🔢 Automatic task numbering
- 🎨 Premium Dark Gaming UI
- 📱 Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- Tailwind CSS
- JavaScript

## 🎨 Design

- Dark Gaming Background
- Neon Cyan Effects
- Purple & Blue Gradients
- Modern Gaming Dashboard

## 📂 Project Structure

Gaming-ToDo-List/
│
├── index.html
├── style.css
├── app.js
└── README.md

## 💻 How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Start managing your tasks!
